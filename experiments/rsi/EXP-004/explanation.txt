EXPERIMENT EXP-004: Path Analysis - Early Exit Detection
================================================================================

OBJECTIVE
---------
Analyze how RSI failures develop bar-by-bar to find early exit opportunities.
Can we detect failures early and exit before big losses?


WHAT WE TESTED
--------------
1. Path Analysis: Track PnL at each bar (1-10) for failures vs successes
2. Early Detection: Can we spot failures at bar 1, 2, or 3?
3. Recovery Analysis: Do failures eventually recover if we wait longer?
4. Catastrophic Failures: Deep dive into the 2 worst failures
